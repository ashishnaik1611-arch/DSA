# 🚀 60-Day DSA Roadmap (LeetCode Focus)

## 🎯 Goal
- Crack interviews (fresher → 2-3 YOE level)
- Build pattern recognition, not just problem memorization
- Minimum 2 problems/day, ideally 4-6
- Be interview-ready on basics across **all** topics well before Day 60 — Tier 1 exists for exactly this
- Cover tough/classic hard interview questions too, not just easy mediums

## 🗂️ How this repo is organized
- `Learning/` — concept notebooks per topic (theory, syntax, mini-snippets)
- `Solutions/<topic>/` — actual LeetCode solutions, one file per problem: `NNNN_problem_name.py`
- `InterviewPrep/` — misc interview-style questions, company-agnostic
- `000_Follow.md` — this file. The single source of truth for the plan & problem list. Check off boxes as you go.

Naming convention for solutions: `Solutions/01_Arrays/0001_two_sum.py`

## 🧠 How to use this list
- Problems are **jumbled across topics on purpose** — interviews don't tell you the topic in advance, so don't train yourself to expect one.
- Two tiers, not two schedules:
  - **Tier 1 — Core Basics (all topics)**: one solid, must-know problem per pattern, covering every topic in the repo. Finish this first (roughly the first ~20-25 days at 2-3/day) and you already have baseline interview coverage on everything — arrays through DP through graphs — even though Tier 2 is untouched.
  - **Tier 2 — Tough & Frequently Asked (mixed)**: harder mediums and hards, still jumbled, for depth and speed. Work through this for the rest of the 60 days.
- Pick problems in list order, or shuffle further if you want more randomness — order within a tier doesn't matter, topic coverage does.
- Don't binge one topic for a week; if you just solved a tree problem, prefer to solve a DP or graph one next, not another tree one. That's the whole point of jumbling.

## ⏱️ Time targets
| Difficulty | Target time |
|---|---|
| Easy | 10-15 min |
| Medium | 25-30 min |
| Hard | 40-45 min |

## 📋 Daily routine
1. Pick 2-6 unsolved problems from Tier 1 first, then Tier 2, in any order.
2. If stuck >20-25 min on a Medium, peek at the pattern name, then re-derive the solution yourself.
3. Write the **pattern name** in a comment at the top of every solution file.
4. Every 5-7 days, re-solve 3-5 already-checked problems cold, no notes (spaced repetition).

# 💬 Rules
1. **After every problem**, ask: *what pattern is this?* — write it in the solution file.
2. **Re-solve** problems after 2-3 days if you struggled.
3. **Time yourself** — Easy 10-15m / Medium 25-30m / Hard 40-45m.
4. Consistency > Intensity. 2/day minimum, never zero.
5. Finish Tier 1 fast (even if imperfectly) — full-topic coverage beats deep-diving one topic early.

Interview-ready checkpoint: as soon as Tier 1 is fully checked off, you have baseline coverage on every topic. Tiers 2-3 build speed and depth for the rest of the 60 days.
